# Своя иконка приложения

Патч добавляет в `Настройки -> Оформление -> Иконка приложения` отдельную бесплатную иконку **«Своя»**.

Важно: iOS не разрешает приложению взять произвольную картинку из Фото и сразу сделать её настоящей иконкой приложения. `UIApplication.setAlternateIconName` работает только с иконками, которые уже лежат внутри подписанного `.ipa`.

Поэтому кастомная картинка в этом форке задаётся при сборке:

1. Положи квадратную картинку в `payload/AyuCustomIcon.png` (также поддерживаются `.jpg` и `.jpeg`). Желательно 1024x1024 или больше.
2. Запусти `Build Telegram Ayu Edit History IPA` или просто закоммить картинку в `main` — workflow стартует автоматически.
3. Скачай новый artifact `.ipa`.
4. В приложении открой `Оформление -> Иконка приложения -> Своя`.

Во время сборки изображение автоматически обрезается по центру до квадрата и создаются все размеры iPhone/iPad/notification icon, нужные Telegram.

Если `payload/AyuCustomIcon.*` отсутствует, сборка всё равно проходит: слот «Своя» использует временную стандартную картинку-заглушку.

Premium-иконки Telegram этим патчем не разблокируются: они остаются под штатной проверкой подписки. Патч добавляет отдельный независимый слот кастомной иконки.
